# Login & Signup Page

A responsive login and signup UI built with HTML, CSS and vanilla JavaScript.

## Features
- Login and signup tab switching
- Responsive layout for mobile, tablet and desktop
- Show/hide password
- Basic form validation
- Password confirmation validation
- Accessible labels and feedback messages

## Run
Open `index.html` in your browser.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive breakpoints
- `script.js` — tab switching and form validation

> This is a frontend practice project. It does not create accounts or authenticate users. A backend and secure authentication system are required for real login/signup.
